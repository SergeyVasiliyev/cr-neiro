# crsim: симулятор Clash Royale для обучения нейросетей

Симуляция боя Clash Royale без графики на C++20 плюс готовая среда для обучения с подкреплением на Python:
пакетный многопоточный прогон матчей, наблюдения и маски действий, награды, боты-соперники,
обёртка Gymnasium, PPO-тренер на PyTorch (GPU), оценка моделей и визуализатор.

## Быстрый старт

```bat
scripts\build.bat                                   :: собрать ядро, тесты и Python-модуль
build\crsim_tests.exe data                          :: тесты ядра
.venv\Scripts\python.exe -m pytest python\tests -q  :: тесты среды
scripts\viewer.bat                                  :: поиграть против бота
scripts\train.bat --run first --opponent heuristic  :: обучить модель
```

Первый раз нужно окружение (Python 3.12):

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install pybind11 pygame numpy gymnasium tensorboard pytest
.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu128
scripts\build.bat
```

## Обучение

```bat
scripts\train.bat --run first --opponent heuristic --total-steps 20e6
scripts\train.bat --run mix --opponent random:0.2,heuristic:0.5,selfplay:0.3
scripts\train.bat --run decks --random-decks 6 --opponent heuristic         :: случайные колоды, все пары
scripts\train.bat --run hog --deck giant,knight,... --opp-deck ...          :: свой матчап
scripts\train.bat --run cont --resume runs\first\latest.pt                  :: продолжить
```

- Агент играет за синих. Наблюдения всегда даются «от своей стороны», поэтому модель потом может играть за любую сторону.
- Соперники: `noop` (стоит), `random`, `heuristic` (защищается и пушит) и `selfplay` (замороженные прошлые версии самой модели). Их можно смешивать в пропорциях.
- Награды: `--reward-win` (победа/поражение), `--reward-tower` (урон по башням), `--reward-crown`, `--reward-leak` (штраф за переполненный эликсир).
- Графики: `.venv\Scripts\tensorboard.exe --logdir runs`, затем открыть http://localhost:6006
- Чекпойнты: `runs\<имя>\latest.pt` (+ копия каждые 200 итераций), текстовый лог: `runs\<имя>\train.log`
- Скорость на RTX 2060 + i7-9700K: около 2800 шагов агента в секунду (≈ 10 млн шагов за час).
  Сама симуляция быстрее (≈ 540 тыс. решений в секунду), упор в нейросеть.

Оценка и просмотр:

```bat
.venv\Scripts\python.exe python\evaluate.py --model runs\first\latest.pt --opponent heuristic --games 500
.venv\Scripts\python.exe python\evaluate.py --model runs\a\latest.pt --opponent runs\b\latest.pt
scripts\viewer.bat --blue runs\first\latest.pt --red heuristic
```

## Среда (python/crsim_env.py)

- `VecEnv` — N матчей параллельно на C++ (OpenMP, все ядра), буферы отдаются в numpy без копирования. Управляются обе стороны; действие `-1` отдаёт ход встроенному боту.
- `CrEnv` — обычный `gymnasium.Env` на один матч против бота или любой функции-политики. Есть `action_masks()` для sb3-contrib MaskablePPO.

Наблюдение — словарь numpy-массивов:

| ключ | форма | что внутри |
|---|---|---|
| `global` | 25 | время, овертайм, множитель эликсира, свой эликсир и **эликсир соперника по видимому** (его скрытые чертежи ещё не вычтены), короны, HP башен, стоимость карт в руке |
| `entities` | 64×14 | башни, юниты, **летящие заклинания** (x, y = куда упадёт, «разворачивается» = секунды до удара) и **свои чертежи** (x, y = где появится, «разворачивается» = секунды до появления): свой/чужой, x, y, HP, воздух, здание, король, разворачивается, атакует, радиус, активен, заклинание, чертёж |
| `entity_token` | 64 | 0 пусто, 1 принцесса, 2 король, 3+ номер карты |
| `entity_mask` | 64 | 1 = в слоте есть объект |
| `hand` | 8 | свой полный цикл: 4 карты в руке, затем очередь по порядку |
| `enemy_history` | 8 | последние **увиденные** карты соперника (появившиеся на поле), новые первыми (0 = ещё не было) |
| `enemy_history_age` | 8 | сколько секунд назад каждая из них появилась / 10 |
| `action_mask` | 2305 | 1 = действие допустимо (заклинания — на любую клетку поля) |

Действие: `0` = ждать, `1 + слот*576 + ряд*18 + столбец` = поставить карту из слота руки на клетку
(своя система координат, своя сторона снизу). Решение принимается раз в 0,5 с (`decision_ticks=10`). Обе стороны решают по одному и тому же
состоянию, потом оба хода применяются: никто не реагирует на карту, сыгранную в тот же момент.
Колода по умолчанию — стартовая: рыцарь, лучницы, миньоны, стрелы, огненный шар, гигант, мини-пекка, мушкетёр.

## Данные карт

Все числа игры живут в `data/`, а не в коде. `cards.json` и `towers.json` генерируются импортёром
прямо из файлов игры (сейчас версия 16.402.21):

```bat
.venv\Scripts\python.exe tools\import_game_files.py --level 11 --version 16.402.21
```

Откуда файлы: Play Market ставит игру вместе с пакетом ресурсов `split_install_time_asset_pack.apk`
(~900 МБ), в нём `assets/csv_logic/` — вся логика игры (сжатые LZMA таблицы CSV/TOML).
Как достать после патча (LDPlayer с root и ADB, игра обновлена):

```bat
C:\LDPlayer\LDPlayer9\adb.exe shell pm path com.supercell.clashroyale
C:\LDPlayer\LDPlayer9\adb.exe pull <папка из вывода>/split_install_time_asset_pack.apk raw\game_update\asset_pack.apk
```

Правила матча (`data/rules.json`) взяты из `battle_timelines.csv` вручную.

Ручные поправки поверх данных игры лежат в `data/overrides.json` (накладываются при загрузке,
переимпорт их не трогает), у каждой указано почему. Сейчас поправок нет.
Старый источник (данные RoyaleAPI, декабрь 2023) остался в `tools\import_royaleapi.py`.

Импортируются все 86 карт-юнитов. У карт, механику которых ядро ещё не умеет (рывок, спавн при смерти,
прыжок через реку, способности чемпионов, скриптовые «действия» и т. д.), есть поле `unsupported`.
Для обучения берутся только полностью поддерживаемые (сейчас 24): `crsim_env.supported_cards(data)`.

Единицы: расстояния в клетках (арена 18×32), `speed` в клетках в минуту как в игре, время в мс.

## Механика ядра

- тики по 50 мс, детерминизм по seed
- розыгрыш карты: эликсир и цикл сразу, затем «чертёж» (`deploy_delay_ms` в `rules.json`, видит только
  сыгравший, задеть нельзя), затем юнит появляется на поле с таймером выставления (уязвим, но не действует)
  или заклинание вылетает из короля; юниты группы появляются с шагом `spawn_stagger_ms` (100 мс)
- эликсир (x1, x2 в последнюю минуту, овертайм), колода 8, рука 4, цикл карт
- зоны выставления с «карманом» после сноса принцессы, запрет ставить на башни
- башни: принцессы и король (просыпается от урона или потери принцессы)
- юниты: движение через мосты, наземные и воздушные, выбор цели, «только здания»
- коллизии с массой (тяжёлые расталкивают лёгких), обход башен, река непроходима вне мостов
- атаки: ближний бой, самонаводящиеся снаряды, сплэш (в том числе вокруг себя), сниженный урон по башням
- заклинания-снаряды (стрелы, огненный шар, ракета): летят из королевской башни, одинаковый урон всем в радиусе,
  волны, сниженный урон по башням, отбрасывание со сбросом атаки (кроме юнитов с иммунитетом, как гигант)
- короны, конец матча, овертайм с внезапной смертью, тайбрейк по HP башен

Ещё нет: заклинания с эффектами (заморозка, яд, бревно и т. д.), здания-карты, эволюции и герои,
спецмеханики из списка `unsupported`, нормальный поиск пути.


## Визуализатор

`scripts\viewer.bat [--blue X] [--red Y] [--blue-deck ...] [--red-deck ...] [--seed N]`, где X/Y — `human`,
`noop`, `random`, `heuristic` или путь к `.pt`. По умолчанию ты за синих, эвристический бот за красных.

Управление: 1-4 или клик по карте — выбрать, ЛКМ по арене — поставить, ПКМ — отмена, Tab — сторона,
B/R — включить/выключить бота или модель за синих/красных, пробел — пауза, стрелка вправо — шаг,
+/- — скорость, T — линии целей, N — новый матч, Backspace — заново.
